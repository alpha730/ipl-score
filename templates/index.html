Example: 10.3 means 10 overs and 3 balls

Model Performance

Models Used

Linear Regression: Baseline model finding relationships between runs, overs, wickets and final score.

Ridge Regression: L2 regularization to prevent overfitting.

Lasso Regression: L1 regularization for feature selection.

Decision Tree: Non-linear splits based on feature thresholds.

Model MSE RMSE R²

Performance Metrics

MSE: Average squared prediction error.

RMSE: Typical error in runs (lower is better).

R²: How well model explains score variance (0-1, higher is better).

How It Works

Enter the current score (runs), overs bowled, and wickets lost. The model analyzes historical IPL data to predict the final innings score. Team strengths and venue are also considered.
